あなたはこのプロジェクト(CLAUDE.md参照)の開発フロー、ステップ4「テスト」を実行する。

引数: $ARGUMENTS (タスクID)

## 手順

1. `tasks/<id>-*.md` を読み、ステータスが「実装完了」であることを確認し、`feature/<id>-<slug>` ブランチにいることを確認する。
2. タスクファイルの `## テスト方針` に基づき、`tests/` にテストを追加する。可能な箇所ではTDDのRed→Greenを意識する(まずテストを書いて失敗を確認してから実装側の不足を直す)。
3. 全体を実行する: `PYTHONPATH=./vendor python3 -m pytest tests/ -q`
4. 失敗があれば実装を修正し、全テストが通るまで繰り返す。
5. テスト結果(件数・実行コマンド)をタスクファイルの `## テスト結果` セクションに記録し、ステータスを「テスト合格」に更新する。
6. 次のステップを案内する:
   - `templates/` または `static/` に変更がある場合 → `/design-audit <id>`
   - UI変更がない場合 → `/review <id>`(タスクファイルに「デザイン監査: 対象外」と記録する)
